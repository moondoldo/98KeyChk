==========================================================================
【PC-98キーボードチェック】98KeyChk Ver 1.0 by MoonDoldo                 =
==========================================================================

■対応機種
- PC-9821 シリーズ
- PC-9801 シリーズ VM以降

■起動方法
- Normal Mode(通常のPC-98キーボード)
98KEYCHK

- WIN・APP Mode(WINキー・APPキーがあるPC-98キーボード)
98KEYCHK /W

■プログラムの終了
[CTRL]+[C]

■仕様
- Normal Mode(通常のPC-98キーボード)
左SHIFTキーと右SHIFTキーを同一のキーとして判定します(どちらも左SHIFTキーとして扱います)

- WIN・APP Mode(WINキー・APPキーがあるPC-98キーボード)
「拡張キーコードの送出を有効」の設定を行い、以下のキーを個別に判定できるようになります
左SHIFTキーと右SHIFTキーを判定します
左WINキーと右WINキーを判定します
APPキーを判定します


純正では無いキーボードについては、多少結果が変わるかもしれません
以下、一例として…

- クラシックPC救済委員会 USB KEYBOARD for PC-98x1 ＋ 108キーボード(JIS配列)
(Normal Mode でも WIN・APP Mode でも、以下の状態となります)
左SHIFTキーと右SHIFTキーを同一のキーとして判定します(どちらも左SHIFTキーとして扱います)
WINキーを右WINキーとして判定します(108キーボードではWINキーは左側に1つしか付いていません)
APPキーを判定します

- クラシックPC救済委員会 USB KEYBOARD for PC-98x1 ＋ 109キーボード(JIS配列)
(Normal Mode でも WIN・APP Mode でも、以下の状態となります)
左SHIFTキーと右SHIFTキーを同一のキーとして判定します(どちらも左SHIFTキーとして扱います)
左WINキー・右WINキーを右WINキーとして判定します(109キーボードではWINキーが左と右に付いています)
APPキーを判定します
