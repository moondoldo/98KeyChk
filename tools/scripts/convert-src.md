# convert-src.ps1

## 目的

`src/` にあるUTF-8のCソースおよびヘッダーファイルをShift-JISへ変換し、`PC98DEV/SRC/` へコピーします。

UTF-8の原本は変更、移動、削除しません。

## 実行方法

`convert-src.bat` を実行します。

PowerShellを直接使用する場合は、次のように実行します。

```bat
powershell -ExecutionPolicy Unrestricted -File "tools\scripts\convert-src.ps1"
```

## フォルダー設定

入力元と出力先は、`convert-src.ps1` 冒頭の次の変数で指定します。

```powershell
$SourceDirectory = "D:\Git\md\98KeyChk\src"
$DestinationDirectory = "D:\Git\md\98KeyChk\PC98DEV\SRC"
```

プロジェクトフォルダーを移動した場合は、この2つのフルパスを変更します。

入力元または出力先のフォルダーが存在しない場合、フォルダーを自動作成せずエラーで停止します。

## 変換仕様

- 入力元の直下にある `.c` と `.h` を変換します。
- 拡張子の大文字と小文字は区別しません。
- 入力元のサブフォルダー内にあるファイルは変換しません。
- 出力先のルートフォルダーは自動作成しません。
- 入力はUTF-8として厳密に読み込みます。
- 出力文字コードはShift-JIS（コードページ932）です。
- 改行コードはCRLFへ統一します。
- Shift-JISで表現できない文字がある場合、`?` に置換せずエラーにします。
- 同名の変換済みファイルがある場合は上書きします。
- 新しいファイルは追加します。
- 出力先だけに存在するファイルは削除しません。
- `README.TXT` など、`.c` と `.h` 以外のファイルは変更しません。

原本側でファイルを削除または改名しても、以前の変換結果は出力先に残ります。不要になったファイルは手作業で削除します。

すべての入力ファイルを変換できることを確認してから出力を開始します。途中に変換できないファイルがある場合、その実行では変換結果を出力しません。

## 終了時の動作

正常終了時は、変換したファイルとファイル数を表示します。

エラー時は、エラー内容を表示してEnterキーが押されるまで待機し、終了コード1で終了します。
