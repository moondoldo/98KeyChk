# PC-98キーボードチェック 98KeyChk

PC-98キーボードのチェック

## 簡易説明

通常モード

```
98KEYCHK.EXE
```

WIN・APPキーモード
```
98KEYCHK.EXE /W
```

プログラムの終了は[CTRL]+[C]で

## テスト済み環境
- Neko Project 21/W<br>
WIN・APP有りキーボードエミュレーション
- PC-9821 Xa10<br>
ノーマルキーボード
- PC-9821 Ce<br>
「クラシックPC救済委員会 USB KEYBOARD for PC-98x1」＋USBキーボード ※一部WIN・APP有り
