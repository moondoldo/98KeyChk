# 98KeyChk 引き継ぎ書

作成日: 2026-07-31

## 現在の目的

Neko Project 21/W上のMS-DOSで動作する、PC-98用キーボード入力確認プログラムをLSI C-86 Ver.3.30c 試食版で開発する。

Windows側で編集するUTF-8のソースと、MS-DOS側でコンパイルするShift-JISのソースを分離する構成を準備している。

## 主要な実装方針

- Git管理する原本は `src/` にUTF-8で配置する。
- `.c` と `.h` はCRLF、MarkdownはLFとする。
- ビルド前に変換スクリプトを実行し、Shift-JISへ変換したファイルを `PC98DEV/SRC/` に出力する。
- `PC98DEV/SRC/` はGit管理から除外し、変換済みファイルを直接編集しない。
- `PC98DEV/` は、Neko Project 21/W内のMS-DOSからHOSTDRV.COMを使って仮想ドライブとして参照する。
- ビルドはNeko Project 21/W内でLSI C-86を手動実行する。
- 詳細な常設ルールはルートの `AGENTS.md` に従う。

## 今日変更した内容

- PC-98、LSI C-86、エミュレータ、ファイル編集に関する常設ルールを `AGENTS.md` に整理した。
- `AGENTS.md` にUTF-8の原本とShift-JISの変換済みファイルを分離するルールを追加した。
- `src/readme.md` に、UTF-8の原本を置くフォルダーであることを記載した。
- `PC98DEV/README.TXT` に、HOSTDRV.COMから参照するフォルダーであることをShift-JIS、CRLFで記載した。
- `.gitignore` に `/PC98Dev/SRC/` を追加した。
- `PC98DEV/SRC/README.TXT` に変換先フォルダーの説明をShift-JIS、CRLFで配置した。このファイル自体もGit管理外である。
- 不要になった旧 `DEVELOPMENT.md` を `docs/archive/20260731_DEVELOPMENT.md` として保管した。
